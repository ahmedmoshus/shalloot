# شلووت – مشروع تطبيق أندرويد

اللعبة موجودة في `www/index.html` (HTML5 Canvas). المشروع يغلّفها بـ Capacitor ويبني ملف APK على سيرفرات GitHub، فلا تحتاج Android Studio.

## خطوات الحصول على APK
1. أنشئ مستودعًا جديدًا على GitHub (مثلًا `shalloot`) وارفع محتويات هذا المجلد إليه (فرع `main`).
2. ادخل تبويب **Actions** ← **Build Android APK** ← **Run workflow** (أو يبدأ تلقائيًا عند الرفع).
3. بعد انتهاء البناء (5–10 دقائق تقريبًا) افتح التشغيل ونزّل **shalloot-apk** من قسم Artifacts، ثم فكّ الضغط وثبّت `app-debug.apk` على الهاتف (فعّل «التثبيت من مصادر غير معروفة»).

## ملاحظات
- هذا APK تجريبي (debug). للنشر على Google Play يلزم توقيع نسخة release.
- لتعديل اللعبة عدّل `www/index.html` وارفع التغيير، ثم أعد البناء.
- الخطوط تُحمَّل من الإنترنت؛ بدون اتصال يستخدم التطبيق خط النظام (اللعبة تعمل بشكل طبيعي).
- الاتجاه مقفول عموديًا.
